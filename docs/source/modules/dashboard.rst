App: Dashboard — Monitoramento
================================

Exibe estatísticas em tempo real de ativações, pedidos pendentes e status por operadora.

.. contents:: Conteúdo
   :local:
   :depth: 2

Funcionalidades
---------------

- Contagem de ativações por operadora (hoje, amanhã, semana, mês)
- Pedidos pendentes ordenados por data de ativação
- Planos de voz pendentes
- Endpoint para limpeza de cache Redis
